## 分步工作

1. 收集服务器操作系统、SSH主机/端口/用户名、授权的登录方式，以及可用目录和磁盘。密钥、密码和令牌不写入项目或工作记录。交接中的4×A100 80GB仅为用户提供的信息，尚未实际检查。
2. 只读检查GPU、驱动、CUDA兼容性、磁盘、Python/容器运行环境、已运行服务和端口；按结果选择独立环境，保留服务器已有部署。
3. 从官方来源核实具体Qwen3.5-9B权重仓库、许可、vLLM版本兼容性与加载方式，再给出固定版本部署文件。当前不提供未经验证的模型仓库ID或显存承诺。
4. 在单卡上加载模型，以明确配置启动OpenAI兼容API，验证模型列表、一次文字请求及所需的图片输入。记录实际服务模型ID与运行版本。
5. 根据实际网络选用受控内网连接或SSH转发，让WSL访问服务；不默认把服务公开到互联网。运行连通、超时、服务错误和响应结构测试。
6. 接入可替换的模型适配器，在同一开发任务上跑Qwen基线，记录调用耗时和实际返回的token用量；未返回的用量记null。
