# Qwen材料提取基线与独立评测

## 实际范围

本轮使用已部署的Qwen3.5-9B，版本为qwen-extraction-baseline-0.1.0，提示词grounded-source-rows-1。模型从可见参考文本提取语义键、文档ID、片段ID和原文值；PDF/Excel字段位置仍由物理解析器发现。程序核验原文连续引用，统一日期格式，处理明确姓名对应关系，保留来源候选，并执行冲突、缺失、签证覆盖和含首尾天数规则。

这是“模型提取 + 程序校验”的基线，不能称为模型独立理解整张表单或直接端到端填报。模型没有接收规则提取结果、答案、注入记录或异常类别；提示词保留可见文档ID用于证据引用。单个人员、受控PDF/Excel表单和UTF-8参考材料的限制继续适用。

每题仅一次模型请求，无自动重试、修补模型回答或规则回退。模型输出必须为sources四字符串行数组；未知键、重复行、非原文引用、截断回答、模型ID不匹配或非法响应会拒绝该题，输出failed且不产生填写建议。语义错误和遗漏未必违反引用约束，仍需要独立评测发现。verified只表示对已提取事实的检查通过，不能证明全部材料已被读取。

本说明保留首轮单请求策略的历史结果。当前CLI默认使用逐文档及一次纠错，详见[逐文档说明](model-document-baseline.md)。

## 运行方式

在WSL中确认SSH转发可用，并确认本地.env内容后：

~~~bash
cd /home/user773/multimodal_agent
set -a
source .env
set +a
.venv/bin/python -m smartfill run-model-baseline data/dev/v0.1.0 --strategy all
~~~

单题命令：

~~~bash
.venv/bin/python -m smartfill fill-model data/dev/v0.1.0/tasks/DEV-001 --output runs/my-model-task/result.json --trace runs/my-model-task/model --strategy all
.venv/bin/python -m smartfill evaluate data/dev/v0.1.0/tasks/DEV-001 runs/my-model-task/result.json
~~~

输出路径须为新的数据集外目录，拒绝覆盖。单题失败退出码为1；批量命令正常生成摘要不等于题目通过，须检查summary.json中的task_statuses、failure_stages和task_pass_rate。

每题保存model/request.json、response.json、必要时error.json，以及result.json。HTTP错误只记录受限错误状态，不保存响应体；成功收到的JSON响应在业务解析前保存。批量先完成并保存全部15份预测，再读取任何GroundTruth；独立评测器复核原文件并按字段位置和结构对齐。请求与响应包含材料，均放在忽略Git的runs/；API密钥不进入请求留痕文件。

## 2026-10-12首轮结果

正式运行目录为runs/qwen-dev-v1-20261012，15次请求；此前DEV-001接通试运行1次，共16次本轮填报请求。部署阶段另有4次文字/图片探针，单独记录。未根据答案修改提示词或重跑挑选成绩。

正式模型请求温度0、非流式、关闭thinking、输出上限4096 tokens；服务上下文8192、单并发、GPU 3，部署精确环境见server-connection-report.json。实际所有回答finish_reason=stop，无输出截断。正式运行耗时合计151.24秒、中位数9.37秒、P95为15.49秒；输入15971 tokens、输出4907 tokens，15题均有服务用量记录。这是顺序执行的一轮耗时，不是稳定吞吐基准。
