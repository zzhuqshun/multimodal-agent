# 数据目录约定

- examples/：随代码提交的两个手工契约样例，使用虚构人员及证件号；不是15组开发集或泛化评测。
- dev/：后续生成的3模板、15组任务。尚未生成。
- validation/：用于方案选择的验证集，与开发集隔离模板族及实体。
- holdout/：锁定的最终评测集，不参与提示词调整、Skills学习或人工调试。
- external/：公开数据原始下载；获取前核验实际版本、许可和再分发条件。

每组任务使用input.json、documents/和独立ground_truth.json；result.json只作为预测结果或明确标注的手工样例。标准答案不得作为参考材料发送给模型。

后续manifest登记版本、种子、模板族、业务实体、数据来源、split、异常标签和人工核验状态。异常任务属于完整任务包的子集，人工核验集可以从留出任务抽取，不能重复计数。

dev、validation、holdout、external的实际文件默认被Git忽略，保留目录标记。仅经审核且许可明确的合成示例适合显式纳入版本控制。
